# FastAPI Best Architecture Plugins

This is the central repository containing the extensions available for [FastAPI Best Architecture](https://github.com/fastapi-practices/fastapi_best_architecture).

## Getting started

See the [plugins docs](https://fastapi-practices.github.io/fastapi_best_architecture_docs/plugin/before.html) for how to develop and publish your plugin.

Looking for plugin ideas? please check [issues](https://github.com/fastapi-practices/plugins/issues).

## Plugin submission

After the plugin repository is public, use the
[fba skill](https://github.com/fastapi-practices/skills) with your AI agent to run the pre-submission
checks and create a marketplace pull request from your own GitHub account.

Publishing runs from the contributor's fork, so commits and the pull request stay attributed to the
plugin author. Validation reads the repository structure and `plugin.toml` without executing plugin
code.
